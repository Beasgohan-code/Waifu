## Roadmap (incremental, no production cutover implied)

- [ ] **Character Studio:** the existing Mini App URL editor can load a record by exact ID, compares current and proposed details, preserves an unchanged media reference, and rejects stale reviewed saves, but it does not upload media. The legacy unconditional catalog API remains for compatibility and does not provide this conflict guard. Private Telegram creation and `/updatechar exact-id media` replacement show signed, expiring reviews after host selection, with explicit publish or cancel; cancellation blocks older reviews of the same command. Replacement displays current/proposed rarity, preserves the ID and ownership, checks the reviewed record again transactionally, and leaves old blobs and public copies untouched. Photos keep rarity; videos/GIFs become AMV Edition. A changed record or unconfirmed external upload requires operator review; copies may be orphaned and are never retried automatically. The original Telegram media remains the visual preview. A guided metadata editor and shared Telegram/Mini App media upload still need design and implementation. Consider bounded bulk editing with previews; never store new media bytes in MongoDB or bypass operator permissions. Full Studio is not implemented yet.
