# SUMMON tracker

This is the current source of truth for remaining work. The project is a prototype; no production deployment, migration, backup/restore, credential rotation, live Telegram test, or live MongoDB verification has occurred.

## Release blockers

- [ ] **Native Wzgram migration verification:** handlers, keyboards, presentation, group protection, API Telegram access, and lifecycle use Wzgram directly; production no longer depends on aiogram. Exercise all commands, aliases, callbacks, service events, rich messages, Unicode fallbacks, ephemeral privacy, sender-chat handling, and permissions with an authorized Telegram test bot. Wzgram's bounded update queue can drop messages under sustained saturation.
- [ ] **Python regression suite:** the existing aiogram-specific tests still import removed APIs/dependencies, so the full suite currently fails collection and CI is not green. Port or remove those legacy tests only after confirming the requested destructive-cleanup repository; do not hide failures or introduce a framework bridge. Nineteen temporary offline Wzgram checks exercised real dispatcher routing, protection, callbacks, privacy/fallbacks, permission checks, peer storage, and lease logic, but they are not retained CI tests. Several existing suites have been adapted to native Wzgram; three legacy test modules remain incompatible.
- [ ] **MongoDB and coordination:** run the new worker session storage, two-stage majority lease acquisition/renewal, concurrent startup, loss/restart and peer-cache behavior on an isolated real replica set and multi-node failover setup. The lease is not a universal fencing or exactly-once guarantee. Verify transactional catches, transfers, gifts, daily claims, notes, auto replies, and the signed snapshot cursor; cursor snapshots require MongoDB 5.0+ and may expire. No real MongoDB was available locally.
- [ ] **Cutover and health:** have an authorized operator stop existing consumers and remove any Bot API webhook before setting `SUMMON_WEBHOOKS_DISABLED_CONFIRMED=true`. Verify old queued updates, MTProto restart/recovery and outage handling. `/health/poller` reports an MTProto RPC observation, not successful polling or delivery. Test monitoring authentication, alerting, queue saturation and platform shutdown; use one consistently configured worker.
- [ ] **Moderation safety:** `/mute`, `/unmute`, `/unban` and `/kick` and their API actions deliberately fail closed: native restriction writes can clear a concurrent ban, and unban has no atomic conditional guard. Use Telegram's own controls; do not re-enable with a check-then-write race. Verify current admin/bot privileges, safe ban/warning actions, and concurrent role changes on Telegram.
- [ ] **API peer availability:** verify that independently authorized no-update API sessions can use the worker's cached peer hashes across sessions; unknown peers must fail closed. Review cache freshness, role revocation, group/member onboarding, least-privilege database grants and session-key isolation.
- [ ] **Render and Vercel:** rehearse the HTTPS same-origin API proxy, cookies, CSRF origins, rate limits behind shared proxy IPs, worker lease, independent monitoring, autoscaling and paid/free platform behavior. The Vercel proxy passed a local real-HTTPS transport check; neither hosting platform has been deployed or verified.
- [ ] **Migration, secrets and recovery:** rotate previously exposed credentials via the authorized operator. There is no importer; review authorized offline exports, explicit ID/rarity mappings, ownership and duplicate quantities. Obtain explicit authorization and confirmation before any backup/restore or cutover, verify encrypted isolated restore and rollback, stop writers, and never overwrite or dual-write the source.
- [ ] **Catalog upload and premium-emoji coverage:** finish and test operator-only Telegram-photo and HTTPS URL commands, atomic audited catalog writes, image limits and public delivery. Photo storage and normalization are only groundwork; no upload command is registered yet. Expand premium-emoji presentation using eligible native surfaces and Unicode fallback, without changing user-authored content. Verify real Telegram behavior and pack rights.
- [ ] **Rarity rollout:** review the 18 reference defaults and the legacy Epic/Special shared spawn bucket with the operator. The source initializes AMV to 10 but its admin fallback says 100; deployed custom weights are unknown. Rehearse MongoDB schema changes and ownership preservation before release.
- [ ] **Accessibility and real clients:** verify Telegram themes, screen readers, narrow layouts, private response fallbacks, native button and emoji eligibility with real clients. Do not claim unverified pack rights or rendering.
