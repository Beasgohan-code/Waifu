- [ ] **Moderation safety:** `/mute`, `/unmute`, `/unban` and `/kick` and their API actions deliberately fail closed: native restriction writes can clear a concurrent ban, and unban has no atomic conditional guard. - [ ] **API peer availability:** verify that independently authorized no-update API sessions can use the worker's cached peer hashes across sessions; unknown peers must fail closed. Review cache freshness, role revocation, group/member onboarding, least-privilege database grants and session-key isolation.

The Vercel proxy passed a local real-HTTPS transport check; neither hosting platform has been deployed or verified.

There is no importer; review authorized offline exports, explicit ID/rarity mappings, ownership and duplicate quantities. Obtain explicit authorization and confirmation before any backup/restore or cutover, verify encrypted isolated restore and rollback, stop writers, and never overwrite or dual-write the source.
